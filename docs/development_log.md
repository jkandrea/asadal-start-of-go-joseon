# 개발 일지

## 2026-09-15

### 부족 진행 시스템 2차 패스

- 부하 세 자리가 찬 뒤 새 부하를 고르면 기존 부하 중 돌려보낼 대상을 직접 선택하는 교체 화면 추가
- 부족 완료 보상 카드의 공용 그리드 CSS 충돌을 수정해 모든 화면 크기에서 위아래 한 열로 표시
- 엔딩 화면을 흐린 배경 위 `contain` 삽화와 별도 문구 영역으로 나눠 신랑을 포함한 원본 전체가 보이도록 수정
- 전황 변화 선택 뒤 상대 부족의 대답을 별도 결과 화면으로 표시
- 설득은 50% 수락/50% 저항으로 분기하고, 설득 후 저항군 처치 악명을 0.5배로 적용
- 강행 시 10% 확률로 남은 적이 실제로 화면 밖으로 도주하며, 도주 중 처치 악명을 5배로 적용
- 도주자가 모두 탈출하거나 쓰러지면 자동으로 다음 부족 보상과 이동 단계로 진행
- 양·돼지처럼 이동속도가 느린 부족도 이동 중 달리기 프레임이 확실히 교대하도록 적별 보행 타이머 적용
- 뱀의 `스미는 독`을 실제 무기 독 부여로 구현하고, `냉혈`은 독 획득 뒤에만 등장하도록 선행 조건 추가
- 일반 스테이지 중반에 부족의 전의가 흔들리는 협상 이벤트 추가
- 설득 시 남은 전투를 생략하고 악명과 부족 신뢰를 얻으며, 강행 시 경험치를 더 얻는 대신 악명 증가
- 각 부족 완료 후 고유 능력 또는 최대 3명의 자동 전투 부하를 선택하는 보상 추가
- 부족 사이를 웅이 직접 달려 이동하는 경로 연출 추가
- 엔딩을 A~H 8종으로 확장하고 악명, 살려준 부족, 영입 부하, 회차 기억으로 판정
- 진엔딩에 환웅·단군왕검·고조선 건국과 곰/호랑이 우화로 전승되는 후일담 반영
- 진엔딩 문구를 환웅과 웅 사이에서 태어난 아이가 단군왕검으로 자라 나라를 세우는 흐름으로 보정
- 여덟 엔딩에 각각 다른 전용 삽화를 추가하고 실제 엔딩 화면과 기억의 전당 카드에 연결
- 호왕과 웅의 기존 건국 삽화를 혼인 동맹으로 탄생하는 전쟁 국가 `진국` 엔딩으로 재구성
- 진엔딩 삽화는 흰 천상 복식의 환웅·웅·단군이 함께 있는 새 장면으로 교체
- 호왕 격파 뒤 처단 또는 조건부 혼인 동맹을 직접 고르는 최후의 선택 추가
- 해금한 엔딩은 기억의 전당에서 삽화와 두 장면 전체를 다시 감상하도록 확장
- 별도 영구 기억 4종을 출정 횟수·뱀 부족 설득·호랑이 후계 엔딩에 연결하고, 최초 발견 수련점과 기억의 전당 기록 카드 추가

### 메타 진행과 홈 화면

- 메인 홈에서 새 출정, 곰의 수련, 기억의 전당으로 진입하도록 구성
- 곰의 수련을 판 시작 선택창에서 제거하고 브라우저 로컬 저장 기반 영구 성장으로 전환
- 수련 비용 1/2/3/4/5점, 무료 전체 회수, 보스·호왕·첫 엔딩 수련점 보상 구현
- 발견한 엔딩 A~H를 기억의 전당에서 다시 확인하도록 구현
- 저장 데이터에 버전을 두어 향후 복수 세이브 슬롯으로 확장할 여지를 남김

### 안정성·성능·밸런스

- 홈, 프롤로그, 튜토리얼, 선택창, 최종장, 패배, 엔딩에서 전투가 멈추는 단일 상태 흐름 적용
- 호왕 처치 직후 부족 선택창이 다시 나타나는 레벨업 충돌 수정
- Phaser를 출정 시 동적 로딩하고 이번 판에 등장하는 부족 에셋만 선로딩하도록 축소
- 일반 스테이지 초기 적을 6~8명 범위로 제한하고 목표를 7/9/보스/13/15/보스로 조정
- 부족 보너스 회수 계산과 보스 광역기 사망 처리, HUD 실시간 갱신 오류 수정
- 영구 진행과 게임 흐름 회귀 테스트 및 브라우저 스모크 테스트 추가

- 선택창이 맵별/영구 성장별로 섞이는 문제를 분리
- 다음 부족 전환 시 라벨과 실제 후보 데이터가 어긋나는 문제 수정

- 선택 상태 표시와 스테이지 전환 안정화 작업이 진행 중

## 메모

현재 프로젝트는 "설계 문서를 구현하는 단계"에서 "실제 한 판 플레이 가능한 프로토타입" 단계로 이동하고 있다.

핵심은 기능 구현이 아니라, 게임이 실제로 이해되고 플레이 가능한 구조가 되는지 검증하는 것이다.

앞으로는 문서 상 설계가 코드와 일치하는지 지속적으로 확인하면서, 실제 테스트 경험을 반영해야 한다.
