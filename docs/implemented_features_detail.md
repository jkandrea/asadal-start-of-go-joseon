# 플레이 가능한 프로토타입 구현 상세

기준일: **2026-09-16**

이 문서는 현재 저장소에 추가된 플레이 기능을 기능 단위로 설명하는 상위 구현 기록이다. `game_concept.md`가 목표 게임의 전체 설계라면, 이 문서는 지금 빌드에서 사용자가 실제로 할 수 있는 일과 코드가 보장하는 규칙을 설명한다.

세부 수치가 많은 영역은 다음 전문 문서로 분리한다.

- [부족 보상 전투 구현 상세](tribe_rewards_implementation.md)
- [Android APK·AAB 패키징 판단과 실행 계획](android_packaging_guide.md)
- [게임 콘셉트 구현 현황](implementation_status.md)

## 1. 현재 한 판의 전체 흐름

```text
홈
 ├─ 곰의 수련
 ├─ 기억의 전당
 └─ 새 출정
      ↓
프롤로그 → 조작 튜토리얼
      ↓
일반 부족 1 → 보스 → 전황 선택 → 결과 → 부족 보상
      ↓                                      │
부족 사이 이동 ←─────────────────────────────┘
      ↓
같은 구조로 무작위 일반 부족 다섯 곳 진행
      ↓
호랑이 부족과 호왕
      ↓
조건부 최종 선택 → 8개 엔딩 중 하나
      ↓
영구 보상 저장 → 홈과 기억의 전당
```

전투는 실제 플레이 상태에서만 갱신된다. 홈, 프롤로그, 튜토리얼, 레벨업, 전황 선택, 선택 결과, 부족 보상, 부하 교체, 이동, 패배, 엔딩 화면에서는 전투 루프를 멈춘다.

## 2. 홈 화면과 출정 준비

홈 화면은 세 기능의 입구다.

- `새 출정`: 새로운 부족 경로를 만들고 프롤로그부터 시작한다.
- `곰의 수련`: 영구 수련점을 다섯 능력에 투자하거나 전부 회수한다.
- `기억의 전당`: 발견한 8개 엔딩의 삽화·결말과 4개 영구 기억을 다시 본다.

홈 상단에는 남은 수련점, 발견한 엔딩 수, 출정 횟수가 표시된다. Phaser 전투 코드는 첫 출정을 시작할 때 동적으로 불러와 홈의 초기 로딩 부담을 줄인다.

## 3. 무작위 부족 경로

- 일반 부족 후보는 쥐, 소, 토끼, 용, 뱀, 말, 양, 원숭이, 닭, 개, 돼지의 11개다.
- 출정마다 한 부족은 우호 부족, 한 부족은 첫 적대 부족으로 뽑힌다.
- 우호 부족을 제외한 후보에서 첫 적대 부족과 추가 네 부족을 뽑아 다섯 일반 부족 경로를 만든다.
- 일반 부족 다섯 곳 뒤에는 마지막 호랑이 부족이 붙는다.
- 경로는 HUD와 이동 화면에서 순서대로 표시된다.

각 부족은 전사 외형, 이동속도, 공격 간격, 공격 범위와 전술 성향이 다르다. 모든 부족에 완전히 고유한 환경 기믹이 있는 단계는 아니며 이 부분은 후속 콘텐츠다.

## 4. 프롤로그와 튜토리얼

프롤로그는 세 장면으로 구성된다.

1. 곰 부족의 평온한 산과 웅의 일상
2. 호랑이 부족의 복종 요구와 첫 충돌
3. 호랑이가 열한 부족에 퍼뜨린 정복 전쟁의 거짓 소문

이후 모바일 조이스틱과 전투 흐름을 설명하는 튜토리얼을 거쳐 실제 원정을 시작한다. 스토리 화면이 열린 동안 적 생성과 공격은 멈춘다.

## 5. 기본 전투와 스테이지 진행

- 웅은 키보드 또는 화면 조이스틱으로 움직인다.
- 기본 공격은 자동으로 주위 적을 타격한다.
- 적은 웅을 추적하고 부족별 전술에 따라 근접, 원거리, 돌진, 독, 지휘 행동을 사용한다.
- 처치하면 경험치, 악명, 스테이지 진행도가 오른다.
- 일반 스테이지 목표는 `5 + 스테이지 × 2`, 보스 스테이지 목표는 보스 한 명이다.
- 일반 스테이지와 보스 스테이지를 지나며 다섯 부족과 호랑이 부족까지 진행한다.

느린 양·돼지 전사를 포함해 적의 이동속도에 맞춘 달리기 프레임 교대가 적용된다. 웅과 적은 공격·피격·이동 상태에 따라 자세와 타격 효과가 바뀐다.

## 6. 전투 중 성장 — 땅의 가르침

레벨업 선택지는 현재 싸우는 부족의 성장 목록에서 나온다. 새 부족 영역에 들어가면 후보 목록은 해당 부족 계열로 바뀌지만 이미 얻은 강화는 원정이 끝날 때까지 유지된다.

- 독과 화상 계열은 기반 효과를 먼저 얻어야 후속 강화가 후보에 등장한다.
- `스미는 독`은 실제 공격에 독을 부여한다.
- `냉혈`은 독 효과를 가진 뒤에만 등장하고 중독된 적에 대한 피해를 강화한다.
- 선택 화면이 열리면 전투가 멈추고 선택 완료 후 재개된다.

일부 맵 성장 항목은 아직 기획 문서의 모든 복합 효과가 아니라 같은 계열의 범용 강화로 작동한다.

## 7. 전황 변화와 부족의 반응

일반 부족 스테이지에서 목표의 절반 이상을 달성하면 남은 전사들의 전의가 흔들리고 선택 화면이 열린다.

### 설득

- 50% 확률로 부족이 웅의 말을 받아들인다.
- 수락하면 남은 전투를 끝내고 악명이 8 감소하며 살려준 부족 수가 1 증가한다.
- 뱀 부족이 수락하면 `뱀 장로의 신뢰` 기억이 열린다.
- 나머지 50%에는 저항한다. 이 경우 이후 일반 적 처치 악명은 기본값의 0.5배다.

### 강행

- 90% 확률로 전사들이 계속 저항한다.
- 10% 확률로 남은 전사들이 화면 밖으로 도주한다.
- 도주 중인 적을 쓰러뜨리면 기본값의 5배 악명이 오른다.
- 모든 도주자가 화면 밖으로 나가거나 쓰러지면 스테이지가 자동 완료된다.

선택 직후 수락·저항·도주 결과를 별도 화면으로 먼저 보여 준다. 확률 결과를 확인하기 전에 전투가 갑자기 재개되지 않도록 결과 확인 단계가 따로 있다.

기본 악명은 일반 적 처치 1, 보스 처치 6이며 위 반응에 따라 일반 적 배율이 달라진다.

## 8. 부족 완료 보상과 부하 교체

일반 부족의 장을 끝내면 다음 중 하나를 고른다.

- 웅이 사용하는 해당 부족 고유 능력
- 자동으로 싸우는 해당 부족 고유 부하

11개 능력과 11개 부하는 이름만 다른 공통 보너스가 아니라 소환, 돌진, 회피, 중첩 상태, 관통, 회복, 보호막, 연쇄 공격과 지원 행동으로 분리되어 있다. 정확한 발동 조건과 현재 기획 차이는 [부족 보상 전투 구현 상세](tribe_rewards_implementation.md)에 기록한다.

적 처치 시 경험치 정수와 골드가 맵에 떨어진다. 웅은 가까이 접근해 줍고, 복주머니 짐꾼은 더 넓은 범위에서 전리품을 끌어당긴다. 획득 골드는 HUD에 누적되며 상점과 소비처는 후속 경제 시스템에서 연결한다.

부하는 최대 세 명이다. 네 번째 부하를 고르면 자동으로 첫 부하를 버리지 않고 다음 정보를 비교하는 교체 화면을 연다.

- 새로 들어올 부하의 이름, 부족, 행동 설명
- 현재 동행 부하 세 명의 이름, 부족, 행동 설명
- 각 부하를 직접 돌려보내는 버튼

교체가 완료되기 전까지 다음 스테이지로 진행하지 않는다.

## 9. 부족 사이 이동

보상 선택 뒤 다음 부족으로 즉시 화면을 바꾸지 않고 짧은 이동 장면을 보여 준다.

- 웅과 현재 부하들이 다음 토템을 향해 직접 달린다.
- 현재 부족과 다음 부족을 표시해 무작위 스테이지를 하나의 여정으로 연결한다.
- 말이나 수레를 사용하지 않아 세계관의 시대 배경을 유지한다.
- 사용자가 계속하기를 누른 뒤 다음 전투 맵을 준비한다.

## 10. 곰의 수련과 영구 성장

새 저장은 수련점 5점으로 시작한다. 각 항목은 최대 5레벨이며 현재 레벨에서 다음 레벨로 갈 때 1, 2, 3, 4, 5점이 든다.

| 수련 | 현재 효과 |
| --- | --- |
| 곰의 발톱 | 레벨마다 기본 공격력 +3% |
| 쑥의 향 | 60초마다 최대 체력의 1.5% × 레벨 회복 |
| 마늘밭 | 2초마다 주변 적에게 공격력의 10% × 레벨 피해 |
| 곰의 포효 | 광역 피해·넉백, 레벨마다 재사용 대기시간 감소 |
| 산의 힘 | 레벨마다 최대 체력 +4% |

전체 회수는 무료이며 지금까지 투자한 비용을 정확히 돌려준다. 수련은 전투 레벨업 후보에 섞이지 않고 출정 전에만 편집한다.

수련점 획득 규칙은 다음과 같다.

- 일반 부족 보스 처치: 1점
- 호왕 처치: 기본 1점 + 최종 보스 추가 3점
- 새 엔딩 최초 발견: 2점
- 새 기억 최초 발견: 2점

같은 엔딩이나 기억을 다시 보아도 최초 발견 보상은 중복 지급하지 않는다.

## 11. 저장 데이터

영구 진행은 브라우저 `localStorage`의 `asadal.meta.v1` 키에 저장한다.

저장 항목은 다음과 같다.

- 저장 버전
- 보유 수련점과 다섯 수련 레벨
- 발견한 엔딩 목록
- 발견한 기억 목록
- 시작한 원정 수, 승리 수, 처치한 보스 수

읽을 때 음수, 최대 레벨 초과, 알 수 없는 엔딩 ID 같은 손상 값을 정상 범위로 보정한다. 현재는 브라우저·WebView 로컬 저장이며 클라우드 저장과 복수 슬롯은 구현하지 않았다.

## 12. 영구 기억 4종

| 기억 | 실제 해금 조건 | 최초 보상 |
| --- | --- | --- |
| 퍼져 나간 거짓말 | 첫 출정을 시작 | 수련점 2 |
| 뱀 장로의 신뢰 | 뱀 부족 설득이 수락됨 | 수련점 2 |
| 산속의 낯선 남자 | 세 번째 출정을 시작 | 수련점 2 |
| 살아남은 호랑이 아이 | `호랑이의 마지막 새끼` 엔딩 최초 발견 | 수련점 2 |

기억의 전당에서 발견 전에는 조건을 직접 밝히지 않는 흐릿한 카드로 보이고, 발견 후에는 이름과 내용을 읽을 수 있다.

## 13. 호왕 이후 최종 선택

호왕을 쓰러뜨리면 즉시 엔딩으로 가지 않고 최종 선택을 제시한다.

- 기본 선택은 호왕을 처단하고 일반 엔딩 판정을 진행한다.
- 악명 45 이상 70 미만, 살려준 부족 2곳 이하, 부하 2명 이상이면 혼인 동맹 선택이 열린다.
- 조건을 만족한 상태에서 혼인 동맹을 고르면 `진국` 엔딩으로 확정된다.
- 조건을 만족하지 않으면 혼인 동맹 버튼은 비활성화되고 부족한 조건을 안내한다.

호왕 격파 횟수도 별도로 저장한다. 한 번 격파하면 다음 출정부터 `포식자의 발톱`, 세 번 격파하면 `외눈 추적자`가 열린다. 홈의 `호랑이의 전승`에서 전승 없음, 능력, 시작 부하 중 하나를 선택하며 선택값은 다음 출정 시작 시 적용된다.

## 14. 엔딩 8종과 판정 우선순위

엔딩은 아래 순서로 판정된다. 위 조건을 먼저 만족하면 아래 조건은 검사하지 않는다.

| 순위 | 엔딩 | 실제 조건 |
| --- | --- | --- |
| 1 | 진국 | 혼인 동맹 선택 + 악명 45~69 + 살려준 부족 2 이하 + 부하 2 이상 |
| 2 | 아사달 | 살려준 부족 4 이상 + 부하 2 이상 + 악명 12 이하 |
| 3 | 잊힌 부족 | 원정 중 잊힌 부족 사건 발견 |
| 4 | 정복자 | 악명 70 이상 |
| 5 | 다섯 부족의 반란 | 악명 36 이상 + 살려준 부족 1 이하 |
| 6 | 곰의 귀환 | 살려준 부족 4 이상 |
| 7 | 환웅을 만났지만 | 두 번째 이상 출정 + 악명 28 이하 |
| 8 | 호랑이의 마지막 새끼 | 위 조건을 만족하지 않은 기본 결말 |

잊힌 부족 사건은 네 번째 일반 부족 구간에서 이미 두 부족 이상을 살렸을 때 35% 확률로 발견된다.

각 엔딩은 전용 삽화를 사용하고 두 장면으로 결말을 보여 준다. 엔딩 화면은 삽화를 잘라 채우지 않고 전체가 보이도록 배치하며, 문구는 별도 영역에 둔다.

## 15. 기억의 전당과 엔딩 재감상

- 여덟 엔딩 카드는 서로 다른 전용 삽화를 사용한다.
- 미발견 엔딩은 흐린 실루엣, 힌트와 잠긴 이름으로 표시한다.
- 발견한 카드를 누르면 실제 엔딩과 같은 두 장면의 문구와 전체 삽화를 다시 본다.
- 엔딩 아래에는 네 개의 영구 기억 카드를 별도 목록으로 둔다.
- `아사달` 삽화는 흰 천상 복식의 환웅·웅·단군을, `진국` 삽화는 호랑이 가죽을 입은 호왕과 웅을 사용해 두 건국 결말을 구분한다.

## 16. 상태 관리와 React·Phaser 경계

- React는 홈, 수련, 프롤로그, 선택창, 보상, 엔딩, 갤러리와 저장을 담당한다.
- Phaser는 웅, 적, 부하, 충돌, 공격, 경험치, 스테이지와 전투 렌더링을 담당한다.
- 두 영역은 `asadal:*` 사용자 이벤트로 상태와 선택을 교환한다.
- `gameFlow.js`가 현재 화면을 단일 게임 단계로 환산하고, `PLAYING`이 아닐 때 Phaser를 일시 정지한다.
- 컴포넌트와 게임 종료 시 등록한 이벤트 리스너를 제거해 재출정 때 중복 실행되지 않게 한다.

## 17. 안정성·성능 작업

- 호왕 처치 직후 일반 레벨업 선택창이 다시 나타나는 충돌을 차단했다.
- 패배, 엔딩, 보상과 스토리 화면에서 적 생성과 공격이 계속되는 문제를 단일 단계 판정으로 막았다.
- 출정 시 Phaser를 동적으로 불러오고 해당 경로에 필요한 부족 에셋 위주로 준비한다.
- 일반 스테이지 초기 적 수와 목표를 줄여 첫 플레이의 과밀도를 완화했다.
- 보스 광역기 사망, 부족 보너스 회수 계산, HUD 실시간 갱신 문제를 수정했다.
- 이동 입력은 창 포커스를 잃거나 문서가 숨겨질 때 초기화한다.

## 18. 자동 검증 범위

Node 테스트 14개가 다음을 검사한다.

- 수련 비용 증가와 전체 회수
- 보스·엔딩·기억의 영구 보상과 중복 방지
- 손상된 저장 데이터 보정
- 전투 일시정지 단계
- 최종 보스 뒤 일반 선택 차단
- 스테이지 목표 계산
- 8개 엔딩과 진국 동맹 조건
- 설득·강행 확률 경계
- 저항·도주 악명 배율
- 느린 부족 달리기 프레임
- 독·화상 강화의 선행 조건

브라우저 스모크 테스트는 실제 화면에서 홈, 수련, 기억의 전당, 엔딩 삽화, 보상 카드, 부하 교체, 전투 진입과 런타임 오류를 확인한다.

## 19. 현재 남은 큰 제작 단위

- 네 기본 무기와 부족별 무기 해금·교체
- 맵별 무료 리롤, 최대 강화 대체 보상, 골드 사용처와 상점 경제
- 부족별 환경 기믹과 더 넓은 중립 사건 풀
- 난이도별 적 조합과 호왕 3페이즈 기술 탈취
- 추가 회차 사건과 무기 해금
- 부족 보상 세부 차이 보정과 장시간 밸런스 계측
- Capacitor Android 프로젝트, 실기기 최적화, 서명과 원스토어 출시 준비
