# 게임 콘셉트 구현 현황

이 문서는 `game_concept.md`를 삭제하거나 축약하지 않고, 현재 플레이 가능한 빌드와 장기 설계를 구분하기 위한 점검표다.

기준일: **2026-09-16**

상세 문서: [플레이 가능한 프로토타입 구현 전체](implemented_features_detail.md) · [부족 보상 전투 구현](tribe_rewards_implementation.md) · [Android APK·AAB 패키징 계획](android_packaging_guide.md)

## 현재 플레이 가능한 핵심 흐름

- 메인 홈, 영구 수련, 출정, 프롤로그, 튜토리얼, 엔딩 갤러리
- 무작위 다섯 부족 경로와 마지막 호랑이 부족, 부족별 외형·이동·전투 성향
- 맵별 성장 선택, 독·화상 선행 능력, 부족 완료 후 서로 다른 11개 고유 능력 또는 11개 고유 행동 부하 선택. 정원이 찼을 때 내보낼 부하를 직접 지정
- 부족 사이를 직접 달려 이동하는 장면과 전황 변화 사건
- 설득 시 50% 수락/50% 저항, 제압 시 10% 도주/90% 저항, 선택 결과 화면 표시
- 설득 뒤 저항군 처치 악명 ×0.5, 도주군 처치 악명 ×5, 전원 이탈 시 자동 스테이지 완료
- 호왕 이후 최종 선택, 조건 기반 8개 엔딩과 엔딩별 전용 삽화. 엔딩 화면은 삽화를 자르지 않고 전체 표시
- 영구 수련점, 4개 영구 기억, 엔딩·기억 최초 발견 보상과 로컬 저장

## 현재 전투에 구현된 부족 보상

- 쥐 소환, 소 돌진, 토끼 회피, 용 화상 표식, 뱀 중첩독, 말 질풍 칼날, 양 보호막, 원숭이 튕김 공격, 닭 광역 울음, 개 사냥 표식, 돼지 누적 성장이 각각 실제 전투에서 발동한다.
- 굴쥐 대장의 처치 가속, 뿔방패 수호자의 돌진·투사체 방어, 달빛 궁수의 무피격 가속, 비늘 화공의 지속 범위 공격, 독침 술사의 독, 초원 기수의 관통, 구름 치유사의 회복·보호막, 돌팔매 재주꾼의 연쇄 공격, 새벽 북잡이의 광역·공속 지원, 검은 사냥개의 집중 공격, 복주머니 짐꾼의 성장 지원이 서로 다른 로직으로 작동한다.
- 새끼 쥐는 전용 투명 스프라이트와 소환 링으로 표시되며, 경험치 정수·골드 드롭과 복주머니 짐꾼의 자동 수집도 실제 맵 오브젝트로 작동한다.
- 호왕 1회 격파 시 `포식자의 발톱`, 3회 격파 시 시작 부하 `외눈 추적자`가 열리고 홈에서 이번 출정의 호랑이 전승을 선택한다.
- 발동 조건, 수치, 상태값, UI 이벤트, 기획과 현재 구현의 차이는 [부족 보상 전투 구현 상세](tribe_rewards_implementation.md)를 단일 상세 기록으로 사용한다.

## 부분 구현되어 세부 확장이 필요한 항목

- 부족별 전사는 외형과 전술이 다르지만 모든 스테이지가 완전히 별개의 지형 기믹을 쓰지는 않는다.
- 맵 성장 능력은 모두 선택 가능하지만 일부는 문서의 상세 효과 대신 같은 계열의 범용 강화로 동작한다.
- 호왕 전투와 결말 분기는 작동하지만 문서의 모든 3페이즈 기술을 각각 구현한 상태는 아니다.

## 진행에는 필수적이지 않은 후속 제작 단위

아래 항목은 **2026-09-16 현재 없어도 처음부터 호왕 격파와 엔딩 감상까지 진행할 수 있다.** 콘텐츠 폭과 장기 반복 플레이를 확장하는 후속 요소로 관리한다.

- 네 기본 무기와 부족별 무기 해금·교체 시스템
- 맵당 1회 무료 리롤, 모든 강화 최대 시 회복/골드 대체 보상, 골드 사용처와 상점 경제
- 부족별 환경 기믹, 중립 거래·민간인 구출을 포함한 더 넓은 사건 풀
- 난이도 단계별 적 조합과 호왕 3페이즈의 부족 기술 탈취 패턴
- 기억 누적에 따른 추가 사건과 무기 해금
- Android 패키징, 광고 제거와 스킨은 게임 규칙이 아니라 출시 단계 작업으로 분리

위 항목은 한 기능을 켜는 수준이 아니라 각각 전투 밸런스·UI·저장 호환·검증이 필요한 제작 단위다. 이후 작업은 이 목록을 기준으로 완료된 항목을 위쪽으로 이동한다.

## 원스토어 Android 패키징 판단

**결론: APK와 AAB로 패키징할 수 있지만, 현재 저장소에서는 아직 바로 생성되지 않는다.**

2026-09-16 현재 저장소는 React/Vite/Phaser 웹 프로젝트이며 `android/`, Gradle, AndroidManifest, Capacitor 설정이 없다. `npm run build`의 결과는 웹용 `dist/`다. Node.js `v22.22.0`은 Capacitor 8 요구사항을 충족하지만 Android Studio, Android SDK, Capacitor 패키지와 서명 설정이 추가로 필요하다.

Capacitor로 기존 `dist/`를 Android WebView 앱에 포함하면 Android Studio/Gradle에서 Debug APK, 서명 Release APK, Release AAB를 만들 수 있다. 원스토어는 APK와 AAB를 모두 지원한다. 원스토어 AAB는 `minSdkVersion 21` 이상이 필요하지만 Capacitor 8의 Android 지원 하한이 API 24이므로 이 프로젝트는 실제로 API 24 이상을 기준으로 잡게 된다.

설치 명령, APK/AAB 차이, 산출 경로, 서명 키 결정, 게임 생명주기와 실기기 점검표는 [Android APK·AAB 패키징 판단과 실행 계획](android_packaging_guide.md)에 상세히 기록한다.

공식 참고: [Capacitor Android 문서](https://capacitorjs.com/docs/android), [원스토어 Android 바이너리 가이드](https://onestore-dev.gitbook.io/dev/docs/apps/product/android/binary.md)
