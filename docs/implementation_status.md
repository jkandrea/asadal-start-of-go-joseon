# 게임 콘셉트 구현 현황

이 문서는 `game_concept.md`를 삭제하거나 축약하지 않고, 현재 플레이 가능한 빌드와 장기 설계를 구분하기 위한 점검표다.

## 현재 플레이 가능한 핵심 흐름

- 메인 홈, 영구 수련, 출정, 프롤로그, 튜토리얼, 엔딩 갤러리
- 무작위 다섯 부족 경로와 마지막 호랑이 부족, 부족별 외형·이동·전투 성향
- 맵별 성장 선택, 독·화상 선행 능력, 부족 완료 후 고유 능력 또는 최대 3명 부하 선택
- 부족 사이를 직접 달려 이동하는 장면과 전황 변화 사건
- 설득 시 50% 수락/50% 저항, 제압 시 10% 도주/90% 저항, 선택 결과 화면 표시
- 설득 뒤 저항군 처치 악명 ×0.5, 도주군 처치 악명 ×5, 전원 이탈 시 자동 스테이지 완료
- 호왕 이후 최종 선택, 조건 기반 8개 엔딩과 엔딩별 전용 삽화
- 영구 수련점, 4개 영구 기억, 엔딩·기억 최초 발견 보상과 로컬 저장

## 부분 구현되어 세부 확장이 필요한 항목

- 11개 부족 고유 능력은 모두 보상으로 작동하지만 문서의 수치·복합 효과 중 일부는 간략화되어 있다.
- 11개 부족 부하는 모두 영입·교체·자동 전투가 가능하지만 부족마다 완전히 다른 공격 패턴은 아직 공통 추적 공격을 바탕으로 한다.
- 부족별 전사는 외형과 전술이 다르지만 모든 스테이지가 완전히 별개의 지형 기믹을 쓰지는 않는다.
- 맵 성장 능력은 모두 선택 가능하지만 일부는 문서의 상세 효과 대신 같은 계열의 범용 강화로 동작한다.
- 호왕 전투와 결말 분기는 작동하지만 문서의 모든 3페이즈 기술을 각각 구현한 상태는 아니다.

## 후속 제작 단위

- 네 기본 무기와 부족별 무기 해금·교체 시스템
- 맵당 1회 무료 리롤, 모든 강화 최대 시 회복/골드 대체 보상, 골드 경제
- 부족별 부하의 11개 개별 공격 로직과 고유 능력의 문서 수치 완전 일치
- 부족별 환경 기믹, 중립 거래·민간인 구출을 포함한 더 넓은 사건 풀
- 난이도 단계별 적 조합과 호왕 3페이즈의 부족 기술 탈취 패턴
- 호랑이 3회 처치 시작 부하, 기억 누적에 따른 추가 사건과 무기 해금
- Android 패키징, 광고 제거와 스킨은 게임 규칙이 아니라 출시 단계 작업으로 분리

위 항목은 한 기능을 켜는 수준이 아니라 각각 전투 밸런스·UI·저장 호환·검증이 필요한 제작 단위다. 이후 작업은 이 목록을 기준으로 완료된 항목을 위쪽으로 이동한다.
