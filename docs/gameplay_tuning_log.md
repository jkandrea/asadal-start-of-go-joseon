# 게임 로직 튜닝 기록

## 1. 현재 목표

이 문서는 현재 구현된 원형 전투 루프와, 설계 문서와 달라진 실제 게임성 튜닝을 기록하기 위해 작성한다.

핵심 우선순위는 다음과 같다.

- 적이 실제로 이동하고, 플레이어를 추격하는지 확인
- 공격과 피격 판정이 시각적으로 읽히는지 확인
- 스테이지 목표와 다음 부족 전환 흐름이 이해 가능한지 확인
- 영구 수련과 맵 전용 강화가 서로 섞이지 않고 분리되어 있는지 확인
- 보스 전투와 보통 전투가 구분되며, 한 판을 돌릴 수 있는 구조를 만들기

## 2. 구현된 핵심 시스템

### 2.1 기본 전투 루프

- 플레이어는 이동과 자동 공격을 수행한다.
- 적은 플레이어를 향해 추적한다.
- 적이 근거리 접근 시 공격 범위 원과 공격 라인이 보인다.
- 플레이어는 일정 간격으로 공격 이펙트와 슬래시가 발생한다.
- 적 처치 시 경험치와 킬 수가 누적된다.
- 스테이지 목표를 달성하면 다음 부족으로 전환한다.

### 2.2 스테이지 구조

- 일반 스테이지는 적 처치 목표를 달성하면 클리어한다.
- 3스테이지마다 보스 스테이지가 등장한다.
- 보스는 일반 적보다 더 높은 체력과 데미지를 가진다.
- 보스 처치 후에는 큰 보상과 다음 부족 전환을 연동한다.

### 2.3 공격/피격 가시성 개선

- 적 및 플레이어의 공격 반경을 원 형태로 표시한다.
- 공격 직후 짧은 라인 이펙트와 원형 충격 이펙트를 생성한다.
- 적에게 입힌 데미지와 경고 피드백 텍스트를 띄운다.
- 적끼리의 시각적 혼동을 줄이기 위해 근접 경고 상태를 분명하게 만든다.

### 2.4 성장 구조

- 곰의 수련은 출정 전 영구 성장 항목으로 분리한다.
- 수련은 최대 5레벨까지 성장한다.
- 각 수련은 포인트를 사용해 투자한다.
- 선택한 수련은 현재 판 동안 유지되며, 판이 끝나도 값이 보존된다.

- 맵 전용 강화는 현재 부족의 전용 리스트만 나온다.
- 다음 맵으로 넘어가면 현재 부족의 강화 목록으로 교체된다.
- 현재 판 안에서만 유지되는 전용 강화 선택지는 별도로 관리한다.

## 3. 현재 구현된 튜닝 포인트

### 3.1 부족 전환 안정화

초기에는 다음 부족 전환 시 현재 부족 인덱스와 선택 후보 인덱스가 서로 어긋나며, 선택창과 라벨이 불일치하는 문제가 발생했다.

이 문제는 다음 원인으로 정리되었다.

- `currentTribeIndex`와 `window.__asadalTribeIndex`가 서로 다른 경로에서 갱신되었다.
- 전투 종료 후 다음 스테이지 진입에서 스테이지 번호와 부족 인덱스가 일치하지 않는 경우가 있었다.
- 선택 후보 생성 함수가 안전한 인덱스를 보장하지 않았다.

해결책:

- `setStageState()`와 `advanceStage()`를 하나의 전환 경로로 통일
- 각 스테이지 이동 시 `window.__asadalTribeIndex`를 함께 갱신
- `emitChoices()`에서 안전한 인덱스로 정리

결과적으로 현재는 라벨과 실제 스킬 후보가 잘 맞게 유지된다.

### 3.2 선택 화면 정보 표시

선택 화면에서 어떤 항목이 선택되었는지 모르던 문제를 개선했다.

다음 정보를 표시하도록 정리했다.

- 선택창 종류: 곰의 수련 vs 부족 전용 강화
- 남은 수련점 수량
- 현재까지 선택한 수련 목록과 레벨

이는 운영적으로 플레이어가 자신의 빌드를 확인할 수 있게 만든다.

### 3.3 영구 수련과 지역 강화 분리

기존 구조에서는 모든 능력치가 하나의 목록 안에서 섞여버려서, 맵별 특성과 영구 수련이 뒤섞이는 문제가 있었다.

이제는 다음과 같이 분리한다.

- 곰의 수련: 출정 전 투자, 전체 판에 유지
- 맵 전용 강화: 현재 부족 전용, 현재 판 동안만 유지
- 부족 보상: 별도 확장 가능

이 구조는 문서의 설계 의도와 실제 로직을 맞추는 데 의미가 있다.

실전 플레이가 너무 빠르게 끝나거나, 적이 갑작스럽게 압도하지 않도록 한 번 더 밸런스를 조정했다.

### 5.1 플레이어 전투 능력

- 기본 공격력: 18 → 22
- 공격 간격: 0.8 → 0.7초
- 공격 범위: 64 → 72
- 의미: 히트 판정이 더 분명해지고, 타이밍이 안정적으로 느껴지도록 조정

### 5.2 적 전투 능력

- 일반 적 체력: 34 → 28
- 일반 적 데미지: 9 → 6
- 보스 체력: 180 → 150
- 보스 데미지: 16 → 12
- 의미: 보스는 무게감이 남아 있으되, 한 판이 길어지지 않도록 완화

### 5.3 스테이지와 스폰 구조

- 일반 스테이지 목표: 최소 8, 증가폭 조정, 현재 5~기본값으로 완화
- 적 최대 소환량: 10 → 8 수준으로 조정
- 보스 보상 XP: 40 → 30, 평판: 10 → 12
- 의미: 클리어 흐름이 느리게 느껴지되, 너무 압박되지 않게 유지

### 5.4 보상/회복 흐름

- 플레이어가 너무 빠르게 회복해 난이도를 무너뜨리는 상황 방지

## 6. 현재 상태 요약

현재 프로토타입은 "설계 문서의 구조를 구현하는 단계"에서 "한 판이 실제로 돌아가는 프로토타입" 단계로 이동하고 있다.

핵심은 다음과 같다.

- 전투 루프는 실제 동작한다.
- 스테이지/보스 전환이 동작한다.
- 영구 수련과 맵 강화 구분은 일부 반영되었다.
- 선택 상태 추적과 전환 상태 정리가 거의 마무리 단계다.

이 시점에서는 실제 플레이 테스트를 하며 밸런스와 오류를 보완하는 것이 가장 중요하다.
